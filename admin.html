Add a Product

Local tool — connect your site folder, fill the form, submit. It writes the image and updates products.js directly. Works in Chrome or Edge.

Not connected — click below to select your site folder.

If "Connect Site Folder" doesn't work when opening this file directly (double-click), run a local server instead: open a terminal in your site folder and run python3 -m http.server, then visit http://localhost:8000/admin.html.

After adding products, remember to commit & push the changed files (products.js and the new image) to GitHub.
